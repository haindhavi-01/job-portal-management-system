# Job Portal Management System

A full-stack job portal application developed using Python, Django, Django REST Framework, and SQL.

## Features

- Job listing and management
- Job search
- Job filtering by location, category, and company
- RESTful APIs
- Job application management
- CRUD operations
- Django Admin dashboard
- Database management using Django ORM
- Responsive web interface

## Technologies Used

- Python
- Django
- Django REST Framework
- SQL
- SQLite
- HTML
- CSS
- JavaScript

## API Endpoints

- `/api/jobs/`
- `/api/applications/`
- `/admin/`
